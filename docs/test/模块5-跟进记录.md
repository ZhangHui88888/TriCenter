## API 5.1 跟进记录列表

### 请求格式

```http
GET /api/follow-ups?keyword=&type=&enterpriseId=&page=1&pageSize=10
Authorization: Bearer <token>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | string | 否 | 关键词（搜索跟进内容） |
| type | string | 否 | 跟进类型：电话/视频/拜访/会议 |
| enterpriseId | number | 否 | 企业ID |
| page | number | 否 | 页码，默认1 |
| pageSize | number | 否 | 每页数量，默认10 |

### 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "enterpriseId": 1,
        "enterpriseName": "测试企业",
        "followDate": "2026-02-03",
        "followerName": "管理员",
        "followType": "电话",
        "content": "首次电话沟通",
        "status": "初步接触",
        "nextPlan": "下周拜访",
        "stageFrom": "POTENTIAL",
        "stageTo": "HAS_DEMAND",
        "createdAt": "2026-02-03T10:00:00"
      }
    ],
    "total": 1,
    "page": 1,
    "pageSize": 10
  }
}
```

### 测试用例

| 场景 | 请求入参 | 预期响应 | 实际结果 | 状态 |
|------|----------|----------|----------|------|
| 获取全部列表 | page=1&pageSize=10 | 返回分页列表 | | ⬜ |
| 按企业筛选 | enterpriseId=1 | 返回该企业的跟进记录 | | ⬜ |
| 按类型筛选 | type=电话 | 返回电话类型的记录 | | ⬜ |
| 关键词搜索 | keyword=沟通 | 返回内容包含"沟通"的记录 | | ⬜ |
| 无Token访问 | 不带Authorization | 401 未授权 | | ⬜ |

## API 5.2 新增跟进记录

### 请求格式

```http
POST /api/follow-ups
Authorization: Bearer <token>
Content-Type: application/json

{
  "enterpriseId": 1,
  "followType": "电话",
  "followDate": "2026-02-03",
  "content": "首次电话沟通，了解企业基本情况",
  "status": "初步接触",
  "nextPlan": "下周安排拜访",
  "stageAfter": "HAS_DEMAND"
}
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| enterpriseId | number | 是 | 企业ID |
| followType | string | 是 | 跟进类型：电话/视频/拜访/会议 |
| followDate | string | 是 | 跟进日期（YYYY-MM-DD） |
| content | string | 是 | 跟进内容 |
| status | string | 否 | 整体状态 |
| nextPlan | string | 否 | 下一步计划 |
| stageAfter | string | 否 | 变更后阶段（填写则同时变更企业阶段） |

### 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "enterpriseId": 1,
    "enterpriseName": "测试企业",
    "followDate": "2026-02-03",
    "followerName": "管理员",
    "followType": "电话",
    "content": "首次电话沟通，了解企业基本情况",
    "status": "初步接触",
    "nextPlan": "下周安排拜访",
    "stageFrom": "POTENTIAL",
    "stageTo": "HAS_DEMAND",
    "createdAt": "2026-02-03T10:00:00"
  }
}
```

### 测试用例

| 场景 | 请求入参 | 预期响应 | 实际结果 | 状态 |
|------|----------|----------|----------|------|
| 正常新增 | 完整参数 | 201 创建成功 | | ⬜ |
| 同时变更阶段 | 包含stageAfter | 创建成功，企业阶段变更 | | ⬜ |
| 缺少企业ID | enterpriseId为空 | 400 参数错误 | | ⬜ |
| 缺少跟进类型 | followType为空 | 400 参数错误 | | ⬜ |
| 缺少跟进日期 | followDate为空 | 400 参数错误 | | ⬜ |
| 缺少跟进内容 | content为空 | 400 参数错误 | | ⬜ |
| 企业不存在 | enterpriseId=99999 | 400 企业不存在 | | ⬜ |
| 无Token访问 | 不带Authorization | 401 未授权 | | ⬜ |
