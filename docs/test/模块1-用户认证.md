## 1.1 POST /api/auth/login - 用户登录

### 基本信息

| 项 | 值 |
|-----|-----|
| 认证要求 | 🔓 公开 |
| 前置条件 | 无 |

### 请求格式

```http
POST /api/auth/login
Content-Type: application/json

{
  "username": "string (必填, 用户名)",
  "password": "string (必填, 密码)"
}
```

### 响应格式

**成功响应 (200):**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzUxMiJ9...",
    "user": {
      "id": 1,
      "username": "admin",
      "role": "admin",
      "name": "系统管理员"
    }
  },
  "timestamp": 1706947200000
}
```

| 序号 | 测试场景 | 请求入参 | 预期HTTP状态码 | 实际结果 | 状态 |
|------|----------|----------|----------------|----------|------|
| 1 | 正常登录 | `{"username":"<TEST_USER>","password":"<TEST_PASSWORD>"}` | 200 | 设置安全 Cookie | ✅ |
| 2 | 用户名为空 | `{"username":"","password":"<TEST_PASSWORD>"}` | 400 | 参数校验失败 | ✅ |
| 3 | 密码为空 | `{"username":"admin","password":""}` | 400 | 参数校验失败 | ✅ |
| 4 | 用户名不存在 | `{"username":"notexist","password":"123456"}` | 401 | 用户名或密码错误 | ✅ |
| 5 | 密码错误 | `{"username":"admin","password":"wrongpwd"}` | 401 | 用户名或密码错误 | ✅ |
| 6 | SQL注入测试 | `{"username":"admin' OR '1'='1","password":"x"}` | 401 | 拒绝，无注入 | ✅ |
