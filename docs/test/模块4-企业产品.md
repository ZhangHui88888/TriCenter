## 4.1 添加企业产品

### 请求格式

```
POST /api/enterprises/{enterpriseId}/products
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "智能园艺工具套装",
  "categoryId": 1,
  "certificationIds": [1, 2],
  "targetRegionIds": [1, 2],
  "targetCountryIds": ["US", "DE", "JP"],
  "annualSales": "800万元",
  "localProcurementRatio": "70%",
  "automationLevelId": 1,
  "annualCapacity": "30万件",
  "logisticsPartnerIds": [1, 2]
}
```

### 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "enterpriseId": 14,
    "name": "智能园艺工具套装",
    "categoryId": 1,
    "categoryName": "电子产品",
    "certificationIds": [1, 2],
    "certificationNames": ["CE认证", "SGS认证"],
    "targetRegionIds": [1, 2],
    "targetRegionNames": ["欧洲", "北美"],
    "targetCountryIds": ["US", "DE", "JP"],
    "annualSales": "800万元",
    "localProcurementRatio": "70%",
    "automationLevelId": 1,
    "automationLevelName": "高度自动化",
    "annualCapacity": "30万件",
    "logisticsPartnerIds": [1, 2],
    "logisticsPartnerNames": ["DHL", "顺丰"],
    "createdAt": "2026-02-03T14:37:30",
    "updatedAt": "2026-02-03T14:37:30"
  }
}
```

### 测试用例

| 测试场景 | 请求入参 | 预期响应 | 实际结果 | 状态 |
|----------|----------|----------|----------|------|
| 正常添加产品 | name="智能园艺工具套装" | 200, 返回产品信息 | 符合预期 | ✅ |
| 产品名称为空 | name="" | 400, 产品名称不能为空 | 符合预期 | ✅ |

}
