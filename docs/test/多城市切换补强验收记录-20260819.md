## 本次补强结论

- 选城与顶栏切换复用同一个城市会话事务；只有服务端成功签发新 JWT 后才原子替换本地会话。
- 重复点击只会产生一个选城请求；请求失败保留原城市、原页面和原数据。
- 切换成功后清空企业筛选/分页和城市草稿状态，按新 `currentCity.id` 重新挂载内容区并进入概览看板。
- 仅当当前标签的写入表单已修改或存在待保存附件时才弹出确认；筛选、分页和纯浏览不提示。
- 所有 POST/PUT/PATCH/DELETE 请求统一计数，存在未完成的写请求时禁止切换。
- 表单保护已接入企业详情、跟进、合作服务、服务商、字典、用户权限和市场报告的写入弹窗。
- `BroadcastChannel("tricenter-auth")` 与 `storage` 回退通道同步登录、退出和城市变更；其他标签直接放弃本地草稿并进入目标页。
- 同步事件仅包含版本、事件 ID、来源标签 ID、城市 ID、目标页和时间戳，不包含 token 或密码。

## 稳定认证错误契约

| 场景 | HTTP | `errorKey` | 前端行为 |
|------|------|------------|----------|
| 待选令牌访问业务接口 | 403 | `CITY_SELECTION_REQUIRED` | 保留会话，进入选城页 |
| 当前城市撤权或停用 | 403 | `CITY_ACCESS_REVOKED` | 清理会话，返回登录页 |
| 令牌过期或格式无效 | 401 | `TOKEN_EXPIRED` | 清理会话，返回登录页 |
| 账号停用 | 401 | `ACCOUNT_DISABLED` | 清理会话，返回登录页 |
| 普通业务权限不足 | 403 | 无城市错误键 | 仅提示权限不足，不退出 |

## 浏览器验收清单

| 场景 | 验收结果 |
|------|----------|
| 常州单城市账号登录后直接进入，顶栏无切换入口 | ✅ `manager` 直接进入常州看板，未显示切换按钮 |
| 双城市账号每次登录都先选城 | ✅ `admin` 重新登录后进入选城页，可选择常州或苏州 |
| 纯浏览直接切换，实际改动表单后出现确认 | ✅ 企业列表直接切换；“新增跟进记录”录入草稿后提示未保存内容 |
| 取消切换后保留原城市和草稿 | ✅ 取消后仍停留苏州跟进页，表单内容保持不变 |
| 确认切换后放弃草稿并返回目标城市看板 | ✅ 确认后进入常州概览，旧弹窗和草稿均清除 |
| 保存或取消表单后不再误提示 | ✅ 取消“新增跟进记录”后可直接切换，无二次确认 |
| A 标签切换后 B 标签直接同步且放弃草稿 | ✅ A 切到苏州后，B 自动进入苏州看板，未弹确认且草稿被放弃 |

浏览器复验过程中发现，写入弹窗的遮罩会拦截顶栏城市按钮，导致用户无法触发既定的草稿确认流程。现已将城市切换按钮提升到遮罩层上方；复验确认下拉菜单、取消切换和确认切换均可正常操作。
