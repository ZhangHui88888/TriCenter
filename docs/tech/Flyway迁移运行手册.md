# Flyway 迁移运行手册

## 空数据库

创建空的 `tricenter` 数据库并为应用账号授权后启动应用。Flyway 会依次执行 `V001` 至最新版本。脚本不会创建数据库、默认用户或测试业务数据。

## 现有生产数据库

1. 停止写流量，备份数据库和附件，并验证备份可恢复。
2. 对照 `V001`、`V002` 校验全部表、列、索引、外键和参考数据。
3. 仅当校验完全一致时，人工执行 `flyway baseline -baselineVersion=2`。
4. 再启动新版本，让 Flyway 从 `V003` 开始升级。

`baseline-on-migrate` 必须保持关闭。任何不一致都应先形成新的向前 migration，不得修改已发布脚本或跳过校验。

## 回退

`migrations/rollback/` 不在 Flyway 扫描路径中，只供人工评审。执行任何回退前必须备份并取得二次确认；应用版本回滚优先依赖向后兼容的数据库变更。
